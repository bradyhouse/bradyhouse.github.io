# bradyhouse.github.io

My _in-browser_ POC (aka fiddle) collection.


## Security note

Dependabot alerts are deliberately **disabled** for this repository. The `fiddles/`
tree is an archive of ~40 historical learning projects (Angular/Ember/Meteor/React/
Node, some a decade old) whose committed lockfiles trip hundreds of advisories.
Nothing here installs or runs those dependencies — the site serves static files
only — and "fixing" the archives would falsify them. Live projects (the cathode
demo) are built elsewhere and copied in as static assets.
